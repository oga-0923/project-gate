# PROJECT GATE

株式会社AMITOA の 3D カードバトルゲーム（Web版）。

**▶ プレイ：https://oga-0923.github.io/project-gate/**

- ブラウザだけで遊べます（スマートフォン・PC）
- Meta Quest などのブラウザで VR / MR プレイに対応（WebXR）
- 対応言語（12言語）：日本語・English・简体中文・Español・한국어・Português・हिन्दी・العربية・Français・বাংলা・Русский・Bahasa Indonesia
- セーブデータはお使いのブラウザに保存されます
- **アプリとしてインストールできます**：iPhoneはSafariの共有ボタン →「ホーム画面に追加」、AndroidはChromeのメニュー →「アプリをインストール」。全画面で起動し、一度開けばオフラインでも遊べます

Web版は無料公開です（ゲーム内の購入機能は準備中のため動作しません）。
